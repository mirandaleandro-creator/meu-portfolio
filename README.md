## 🛠️ Tecnologias Utilizadas

As seguintes ferramentas e tecnologias foram usadas na construção deste projeto:

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização, Flexbox, Grid e Layout Responsivo)
- **FontAwesome** (Ícones)
- **Git & GitHub** (Controle de versão e hospedagem)

## 📱 Funcionalidades

- **Design Responsivo:** Adaptado para telas de computadores, tablets e celulares.
- **Menu Fixo:** Navegação fluida entre as seções da página.
- **Seção de Projetos:** Cards interativos para exibir trabalhos realizados.
- **Links de Contato:** Acesso direto às minhas redes profissionais e e-mail.
